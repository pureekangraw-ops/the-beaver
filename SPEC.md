# The Beaver private demo
Keep the Stitch undo storefront and the pinned private Beaver image engine. The demo exposes only the static shop and the two existing synchronous PNG operations; no order history, admin routes, job storage or factory credentials. No production changes. Use an isolated Node deployment with HTTPS. Authenticate the browser with a dedicated Cloudflare Access application and one verified email; authenticate ChatGPT MCP separately with Cloudflare Access Managed OAuth, a different Access JWT audience and the same allowlisted email. The only MCP tool opens the storefront; the browser uploads PNG and downloads ZIP directly, never passing PNG bytes or bearer credentials through chat. Do not deploy until both identity policies and an isolated host are confirmed. Acceptance: approved backup account opens the tool, signs in to the private shop, processes one PNG and opens the 18-file ZIP; unauthenticated/other identity denied.
