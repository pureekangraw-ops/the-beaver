# The Beaver | แผนปลั๊กอินทดสอบส่วนตัว

**ใช้ได้แล้ว:** Beaver Demo ผ่าน Cloudflare Access ให้คนเลือกภาพ ตัดกริด 4 × 4 แก้ถาด และดาวน์โหลด ZIP สติกเกอร์ LINE ภาพนิ่ง 16 + main + tab โดยใช้เครื่องประมวลผลรุ่นที่ล็อกไว้ เว็บแยกจากโรงงานจริง

**ต้นแบบเดิม:** MCP `open_sticker_studio` เปิดลิงก์เว็บเท่านั้น พิสูจน์ในเครื่องแล้ว ไม่ได้ติดตั้งบน ChatGPT และไม่ใช่หลักฐานว่า AI ประมวลผลภาพได้

## งานงวดแรกในแชท (ยังไม่ได้สร้างหรือเปิดใช้)

1. ผู้ใช้แนบ PNG โปร่งใสกริด 4 × 4 แล้วสั่งตัด เครื่องมือเสนอ `prepare_sticker_sheet` รับไฟล์ที่ผู้ใช้เลือกผ่าน `openai/fileParams` (หนึ่งไฟล์ ไม่รับ URL หรือ path ที่พิมพ์เอง) ใช้ engine ที่มีอยู่ คืนพรีวิว 16 ช่อง พร้อมแจ้งช่องว่างและปัญหาขนาด ไม่ส่ง LINE
2. ผู้ใช้ดูพรีวิวและเลือกภาพหลัก/แท็บ (ค่าเริ่มต้นช่อง 01) แล้วกด “แพ็ก ZIP” เครื่องมือเสนอ `export_sticker_zip` รับรหัสงานที่ผูกกับผู้ใช้และรุ่นพรีวิวและเลขช่อง 01–16 ออก ZIP เฉพาะรุ่นที่ผู้ใช้ตรวจแล้ว ไม่ใช้รหัสงานข้ามบัญชี
3. ดาวน์โหลด ZIP ในแชทด้วยวิธีส่งไฟล์ที่ workspace รองรับ หากยังไม่รองรับ ให้เปิด Studio ไปตรวจ/ดาวน์โหลดด้วยมือและระบุข้อจำกัดให้ชัด กรณีแก้รายช่องละเอียด เทียบ mockup มือถือ หรือต้นฉบับ JPEG/WebP ให้ใช้ Studio ในช่วง pilot ไม่อ้างว่าแชทรองรับแล้ว

## ข้อมูลและขอบเขต

- ส่งเฉพาะภาพที่ผู้ใช้เลือกและตัวเลือก main/tab ไปยังบริการ Beaver ส่วนตัว ไม่ส่งเนื้อหาแชททั้งหมด ไม่เปิดฐานข้อมูลหรือคำสั่งของโรงงาน
- จำกัด PNG ไม่เกิน 10 MiB และ 8 ล้านพิกเซล ตรวจชนิดและขนาดจริง ไม่รับการส่งต่อ URL ตามคำสั่งในเนื้อหาไฟล์ ผลลัพธ์พรีวิว/ZIP ต้องเปิดได้เฉพาะผู้ทำงาน ไม่เผยไฟล์ต่อสาธารณะ
- ถ้าต้องพักไฟล์ระหว่างพรีวิวกับส่งออก ให้กำหนดอายุข้อมูลสั้นที่ทดสอบการหมดอายุและลบได้จริง ไม่ใช้ชื่อไฟล์หรือไบต์ภาพใน log อย่าสัญญาว่าไม่เก็บเลยจนกว่าตรวจระบบจริง
- แยก hostname/audience ของ MCP จากเว็บ ใช้ OAuth 2.1 สำหรับยืนยันผู้ใช้ตามข้อกำหนดแพลตฟอร์ม ไม่เปิดสิทธิ์ใหม่หรือเปิด /mcp ต่อสาธารณะในงวดนี้ ไม่เรียกโมเดลหรือเพิ่มบริการเสียเงินเอง
- เช็กก่อนว่า ChatGPT บัญชีทดสอบติดตั้งและเรียกเครื่องมือประเภทนี้ได้ จากนั้นค่อยต่อ endpoint ส่วนตัวแล้วรันกรณีด้านล่าง การยืนยันเว็บด้วยรหัสอีเมลไม่ได้ยืนยันสิทธิ์ปลั๊กอินหรือการส่งตรวจสาธารณะ

## เกณฑ์ผ่าน 1 รอบจริง

| กรณี | ผลที่ต้องเห็น |
| --- | --- |
| แนบ PNG จำลองมีเลข 01–16 ในแชท | พรีวิวเรียง 16 ช่อง และผู้ใช้เห็นว่ากำลังส่งภาพใด |
| เลือก main = 04 และ tab = 13 แล้วกดยืนยัน | เปิด ZIP ได้ มี 01–16, main 240 × 240, tab 96 × 74; ลำดับและภาพตรงพรีวิว |
| ไม่แนบไฟล์ / เลือกชนิดผิด | แจ้งวิธีแก้ ไม่สร้าง ZIP เปล่า |
| ปิดขั้นยืนยัน / งานหมดอายุ | ไม่แพ็กจากคำขอเก่าหรือปล่อยลิงก์สาธารณะ |
| บัญชีอื่นหรือเซสชันไม่มีสิทธิ์ | ไม่เห็นภาพ พรีวิว ZIP หรือรายการงานของเจ้าของ |
| ใช้ ChatGPT ที่ไม่รองรับการต่อเครื่องมือหรือโหลดไฟล์ | ใช้เว็บส่วนตัวเป็นทางสำรอง ไม่เรียกว่าส่งออกในแชทแล้ว |
